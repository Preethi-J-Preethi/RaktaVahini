# 🩸 Rakta-Vahini – Smart Blood Donor Finder

A simple Android application designed to connect blood donors with recipients efficiently by filtering eligible donors based on blood group and last donation date.

---

## 🚀 Features

- ✅ Add donor details (Name, Blood Group)
- 📋 View donor list using RecyclerView
- 🔍 Filter donors by blood group
- ⏳ Eligibility check (90-day donation rule)
- 📱 Clean and simple user interface

---

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- RecyclerView
- XML UI Design

---

## 🧠 How It Works

- Donors register with their blood group and last donation date
- The app filters and shows only eligible donors
- Eligibility = Donor has not donated in the last 90 days
